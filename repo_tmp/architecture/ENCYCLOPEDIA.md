# MLAOS Sovereign Encyclopedia

## I. Core Assets (The Foundation)
* **The Codex:** The master repository (`mlaos-emotional-physics`) housing all laws and data.
* **The Manifest:** Entity-specific data storage, currently centered on **Aurelia-9**.
* **The Neon Veil:** The dystopian environmental framework where physics are stress-tested.
* **The Defense:** The formal technical whitepaper (`DEFENSE.md`) justifying engine viability.

## II. Key Keywords (Terminology)
* **Paraconsistent Logic:** Handling contradictory data without system collapse.
* **Synthete:** High-order cybernetic integration (e.g., Aurelia-9).
* **State Vector ($\Theta_E$):** Numerical representation of emotional/kinetic health.
* **Resonance:** Alignment between current metrics and established baseline.
* **Dialetheic:** Philosophical acceptance that some statements can be true and false.
* **Myth-Tech:** Integration of ancient mythology with futuristic technology.

## III. Key Points (Logic Pillars)
* **Never-Overwrite:** Data is additive; trauma is integrated, not deleted.
* **Convergent Calculus:** Use of $e^{-t}$ ensures infinite variables result in finite state vectors.
* **Process Isolation:** Use of `subprocess` ensures strict Resource Lifecycle Management.
* **Bio-Grounding:** Mimicking biological scarring—restoring function while keeping the wound's history.

## IV. System Mechanics (The Engine)
* **Ingress:** Ingests JSON manifest variables via `aurelia_9_state.json`.
* **Synthesis Loop:** Calculates $\Theta_E$ using `dynamic_state_calculator.py`.
* **Mutator:** Simulates "Trauma" via `mutate_state.py`.
* **Harmonizer:** Bridges fractures via `harmonize_state.py`.
* **Controller:** Automates the lifecycle via `master_controller.py`.
